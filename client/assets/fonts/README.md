# Noto Sans Thai

Unmodified variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansthai),
retrieved 6 November 2026. Source filename: `NotoSansThai[wdth,wght].ttf`.
Distributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

The Focus prototype names Noto Sans Thai, then Thonburi. The exported reference
matches Thonburi on macOS, so the desktop keeps that face where available and
uses this bundled Noto Sans Thai copy elsewhere. Registration is private to the
process, with system-font fallbacks when private registration is unavailable. No network request or system font
installation occurs when the app starts.

# Study Group portrait sources

Selected on 6 November 2026 for the StudyGroup app's default avatars.
These are individual webtoon illustrations, replacing the earlier book-cover collage.
Original downloaded images are preserved unchanged; circular framing is defined in `web/src/style.css`.

Original work: **Study Group**, written by **Hyungwuk Shin**, art by **Seungyeon Ryu**.
[Official WEBTOON title page](https://m.webtoons.com/en/action/study-group/list?page=1&title_no=3595).

Artwork rights remain with the original creators/rightsholders.
